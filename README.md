# deeplink-doctor

> Statically reconcile an Expo project's **route tree**, its **native deep-link
> config**, and (optionally) its **hosted association files** — and report where
> they disagree.

**Status: early development — not yet usable.** The implementation is being
built incrementally; this README will be filled in (usage, checks, suppression,
examples) once the core is in place.
